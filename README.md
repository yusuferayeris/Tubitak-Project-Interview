# Smooth Cubic Surfaces over a Non-Algebraically Closed Field

Computational work carried out as part of a TÜBİTAK research project on algebraic geometry and finite geometry, using the **Orbiter** system.

## Overview

This repository contains my implementation, experiments, and computational results developed during the project.

The work focuses on computational problems involving finite fields, projective geometry, algebraic curves, graph theory, and incidence structures. The computations were carried out using and extending the **Orbiter** mathematical software system.

## My Contributions

During the project, I extended Orbiter with new functionality and implemented computational procedures for the assigned problems.
